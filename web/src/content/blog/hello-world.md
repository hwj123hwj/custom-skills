# 欢迎来到 Custom Skills Hub 博客

这是博客系统的第一篇文章。从现在起，这里会分享：

- **技能设计思路** — 每个 Skill 背后的设计哲学
- **使用教程** — 如何用 AI Agent 技能提升效率
- **技术随笔** — 个人在 AI、编程、工具方面的心得

## 为什么做博客？

Custom Skills Hub 原本是一个纯技能市场。但随着内容增多，需要一个地方来承载**深度内容**——技能的「为什么」和「怎么用」，而不只是「是什么」。

博客和技能市场互补：
- **技能页面**是结构化的参考文档（API 式）
- **博客文章**是叙事性的实战分享（故事式）

## 写作体验

每篇文章就是一个 Markdown 文件，放在 `src/content/blog/` 下。支持：

- 标准 Markdown 语法
- 代码高亮
- 标签分类
- 自动生成 RSS 订阅源
