## 一次性配置（约10分钟）

### 第一步：创建 Google 服务账号（拿凭证）

1. 打开 https://console.cloud.google.com/ → 登录你的 Google 账号
2. 顶栏点「选择项目」→「新建项目」，名称随意（如 `ga4-analytics`），创建
3. 左侧菜单 →「API 和服务」→「已启用的 API」→ 点「+ 启用 API」→ 搜 `Google Analytics Data API` → 点「启用」
4. 左侧菜单 →「IAM 和管理」→「服务账号」→ 点「+ 创建服务账号」
   - 名称随意（如 `feishu-bot`）→ 创建并继续 → 完成
5. 点进刚创建的服务账号 →「密钥」标签页 →「添加密钥」→「创建新密钥」→ 类型选 **JSON** → 创建
6. **浏览器会自动下载一个 `.json` 文件**，用记事本打开它，**复制全部内容**（从 `{` 到 `}`）

### 第二步：给服务账号加 GA4 读权限

1. 打开 https://analytics.google.com/ → 登录
2. 左下角「管理」→「账号资源管理」→ 点你的账号 →「媒体资源设置」
3. 找到 **媒体资源 ID**（一串数字，如 `123456789`），**记下来**
4. 左侧「媒体资源访问权限管理」→ 点「+ 添加用户」
5. 邮箱填服务账号的邮箱（在 JSON 凭证里的 `"client_email"` 字段，形如 `feishu-bot@xxx.iam.gserviceaccount.com`）
6. 角色选 **阅读者** → 添加

### 第三步：配置 GitHub Secrets

打开你的仓库 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`，添加 3 个：

| Secret 名称 | 值 |
|-------------|---|
| `GA4_PROPERTY_ID` | 第二步记下的媒体资源 ID（纯数字） |
| `GA4_CREDENTIALS` | 第一步下载的 JSON **全部内容**（从 `{` 到 `}`） |
| `FEISHU_WEBHOOK` | 飞书机器人 webhook 地址（下一步获取） |

### 第四步：创建飞书群机器人

1. 打开飞书群 → 右上角「设置」→「群机器人」→「添加机器人」→ 选「自定义机器人」
2. 名称随意（如 `数据播报`）→ 添加
3. 复制 **webhook 地址**（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxx`）
4. 把地址填入上面的 `FEISHU_WEBHOOK` Secret

## 测试

配置完后，在 GitHub 仓库手动触发测试：
`Actions` → `Daily Analytics Report` → `Run workflow`

如果一切正常，飞书群会立即收到一条数据卡片。

## 常见问题

### ❌ 报错 `Permission denied` 或 `403`
服务账号没加 GA4 读权限，回到第二步重做「给服务账号加 GA4 读权限」。

### ❌ 飞书没收到消息但 Actions 显示成功
检查 webhook 地址是否正确，或飞书机器人是否被移出群。

### ❌ 数据全是 0
网站刚接 GA4 不久，数据有 24-48 小时延迟才出现在 API 里，耐心等。
